# Events — request creation and review

Shared environment, seeded accounts and the priority key are in [README.md](README.md).

**In scope:** the `events` module: organiser drafts and submission (`/events/new`, `EventDetailView`), and the coordinator's review page (`/coordinator/events/:id`) with its approve/reject actions and status history.

**Out of scope:** coordinator assignment and reassignment (SCRUM-12 / SCRUM-68), the notifications bell and read API (SCRUM-27), and releasing equipment reservations on rejection (SCRUM-24).

## Event request creation (SCRUM-8)

These cases cover the implemented organiser draft and submission workflow. Run them with the backend and frontend from the current local setup (`http://localhost:8000` and `http://localhost:5173` respectively). Coordinator auto-assignment, reassignment, and submission notifications are intentionally outside SCRUM-8 and are specified separately under SCRUM-12 / SCRUM-68.

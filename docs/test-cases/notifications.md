# Notifications — the bell, attendee notices and reminders

Shared environment, seeded accounts and the priority key are in [README.md](README.md).

**In scope:** `GET /api/v1/notifications`, `GET /api/v1/notifications/unread-count`, `POST /api/v1/notifications/{id}/read`, `POST /api/v1/notifications/read-all`; the bell in the top bar (`NotificationBell.vue`); the database helpers `add_notification` and `notify_registered_attendees`; the reminder functions run by `pg_cron`. Release 1 is in-app only: email was dropped on 2026-10-20 and 114 is out of Sprint 4.

**Preconditions for every case:** migrations `20261021100000`, `20261021110000` and `20261021120000` are applied (pushed to the live project on 2026-10-21). TC-NOTIF-007 and TC-NOTIF-008 also need SCRUM-43's `public.event_registrations` (migration `20261022100000`) and the D56 fix (`20261022120000`); they insert into that table inside a rolled-back transaction. Use throwaway events named `live-check …`: their notices are deleted with them.
